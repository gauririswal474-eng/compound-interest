# JavaScript - Compound Interest Calculation

## Objective
A JavaScript program that calculates compound interest from static (predefined) values, using variables and operators.

## Formula
```
A = P(1 + r/n)^(nt)
```
- A = amount
- P = principal
- r = rate of interest (as a decimal)
- n = number of times interest is compounded per year
- t = time (in years)

Compound interest = A - P

## Values Used
| Variable | Value |
|----------|-------|
| P | 10000 |
| r | 0.05 (5%) |
| n | 1 |
| t | 3 |

## Output
```
The compound interest after 3 years is: 1576.25
```
The result is printed with `console.log()` and also shown on the page.

## Files
- `index.html` - page structure, links the CSS and JS
- `style.css` - styling
- `script.js` - compound interest logic
- `README.md` - project description

## How to Run
Open `index.html` in a browser and press F12 to view the console output.
